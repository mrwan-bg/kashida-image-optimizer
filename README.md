Kashida Image Optimizer is a lightweight WordPress image optimization plugin that automatically creates optimized WebP and AVIF versions of your images while keeping the original files untouched.

Optimize new uploads automatically or process your existing Media Library with batch conversion, re-optimization, and cleanup tools. Fine-tune WebP and AVIF quality settings, use Smart PNG Handling and Smart Content Detection, and choose the best optimized format for faster image delivery.

Features

Automatic image optimization on upload

WebP and AVIF generation

Smart PNG handling with transparency support

Smart Content Detection for photos and graphics

Separate WebP and AVIF quality controls

Quality presets

Batch conversion for existing Media Library images

Re-optimize images using updated settings

Media Library optimization status and quick actions

Original files are preserved and never replaced

Large image protection to reduce server resource usage

Orphan file cleanup

Lightweight, local server-side image processing

Translation-ready with .po and .mo files

Multilingual plugin compatibility, including Polylang

Installation

In your WordPress dashboard, go to Plugins → Add New Plugin.

Click Upload Plugin.

Select kashida-image-optimizer.zip.

Click Install Now.

After installation, click Activate Plugin.

Open Kashida Image Optimizer → Settings.

Configure image quality and optimization options.

Click Save Settings.

Optimize New Uploads

Enable Auto-convert new uploads in the plugin settings to optimize eligible images automatically when they are uploaded.

Optimize Existing Images

Use Batch Convert Existing Library to process images already stored in your WordPress Media Library.

Requirements

WordPress 5.5 or later

PHP 8.0 or later

A compatible server-side image-processing library: Imagick and/or GD

AVIF support: Availability depends on the capabilities of the installed image-processing library and the server environment.

For the latest recommended WordPress environment requirements, see the official WordPress requirements.
