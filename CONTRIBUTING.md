# Contributing to Kashida Image Optimizer

Thank you for your interest in improving Kashida Image Optimizer.

## Reporting Bugs

Before reporting a bug:
- Check existing issues to avoid duplicates.
- Use the Bug Report template.
- Include clear reproduction steps and relevant error messages.
- Specify your plugin, WordPress, and PHP versions.

## Suggesting Features

- Use the Feature Request template.
- Explain the problem the feature would solve.
- Describe the proposed solution and its expected benefits.

## Contributing Code

1. Fork the repository.
2. Create a branch for your changes.
3. Keep changes focused and consistent with the existing code.
4. Test your changes before submitting them.
5. Open a pull request describing the changes and tests performed.

## Development Guidelines

- Follow WordPress coding standards where applicable.
- Prioritize security, performance, accessibility, and compatibility.
- Avoid unnecessary dependencies.
- Do not include credentials, API keys, or private information in commits.

## Questions

For bugs and feature requests, use the repository's GitHub Issues section.
